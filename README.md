# Project: Café Rafa Santana

This project is a responsive static website developed to practice HTML5, CSS3 and Bootstrap fundamentals.
The main goal was to build a clean layout with semantic structure, reusable components and basic navigation between pages.

## 🛠️ Technologies

HTML5 – semantic structure (header, nav, main, footer)
CSS3 – custom styling and layout adjustments
Bootstrap 5 – responsive navigation and layout system
Google Fonts – custom typography
Git & GitHub – version control

## 🧩Features

Responsive navigation menu using Bootstrap
Semantic HTML structure for better readability and accessibility
External CSS file for styling separation
Google Fonts integration for visual identity
Navigation between multiple pages (Home, Recipes, Registration)

## 🎯 What I Learned

Structuring pages using semantic HTML
Using Bootstrap components for layout and navigation
Organizing assets (CSS, images, pages)
Improving accessibility with proper alt attributes
Building a consistent visual identity across pages

## 🚀 Next Improvements

Add JavaScript for form validation
Improve accessibility with ARIA attributes
